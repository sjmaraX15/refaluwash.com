# Search engine visibility

This website is publicly hosted with GitHub Pages. Search engines can crawl the public pages listed in `sitemap.xml`; admin access is excluded from crawling via `robots.txt`.

To request indexing sooner, add `https://sjmarax15.github.io/refaluwash.com/` as a URL-prefix property in Google Search Console, verify ownership using the HTML tag or DNS method offered there, and submit:

`https://sjmarax15.github.io/refaluwash.com/sitemap.xml`

You can also submit the sitemap in Bing Webmaster Tools. Indexing and ranking are controlled by each search engine and are not immediate or guaranteed.
